📁 Thư Mục chatbot-widget Mẫu

Toàn bộ mã nguồn đã được đóng gói độc lập trong thư mục chatbot-widget:

chatbot-widget/ ├── 📄 config.js // Điền API Key, tên bot, system prompt & câu hỏi gợi ý ├── 🎨 style.css // Toàn bộ kiểu dáng giao diện Dark-Glassmorphism & hiệu ứng ├── ⚡ script.js // Xử lý DOM, gửi tin nhắn, gọi API OpenAI & Mock Fallback └── 🌐 index.html // Trang Demo và hướng dẫn nhúng
🚀 Hướng Dẫn Nhúng Vào Trang Web Chính

Để nhúng Chatbot AI vào bất kỳ trang web nào của bạn (HTML, WordPress, React, PHP...), chỉ cần làm theo 2 bước đơn giản sau:

1
Nhúng CSS vào thẻ <head>
Thêm tệp style.css vào phần đầu trang web của bạn.
2
Nhúng Script trước </body>
Nhúng lần lượt config.js và script.js ở cuối tệp HTML.

Mã nguồn nhúng mẫu (Copy & Paste):

<!-- 1. Thêm CSS vào thẻ <head> --> <link rel="stylesheet" href="chatbot-widget/style.css" /> <!-- 2. Thêm JavaScript vào cuối trang trước thẻ đóng </body> --> <script src="chatbot-widget/config.js"></script> <script src="chatbot-widget/script.js"></script>
⚙️ Hướng Dẫn Cấu Hình API Key

Mở tệp chatbot-widget/config.js và cập nhật giá trị API_KEY với OpenAI Key của bạn:

window.CHATBOT_CONFIG = { // Nhập API Key OpenAI của bạn tại đây API_KEY: "sk-proj-YourActualOpenAiApiKeyHere...", // Đổi tên Bot theo thương hiệu của bạn BOT_NAME: "AI3D Assistant", // Cấu hình System Prompt SYSTEM_PROMPT: "Bạn là trợ lý tư vấn bán hàng chuyên nghiệp..." };

💡 Mẹo: Nếu bạn để trống API_KEY: "", chatbot sẽ tự động chuyển sang chế độ Mock AI Mode phản hồi thông minh các câu hỏi về sản phẩm, bảo hành, trả góp để bạn thử nghiệm giao diện ngay lập tức mà không tốn phí API!
